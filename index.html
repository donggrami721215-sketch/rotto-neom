LOTTO 6/45

로또 번호 도우미

추천부터 통계와 당첨 확인까지 한곳에서 이용하세요.

1

추천 조건 설정

게임 수와 포함할 번호를 선택하세요.

1~100게임을 입력할 수 있습니다.

최신 당첨 다음 회차가 자동 입력됩니다.

포함할 번호 선택 사항

모든 게임에 넣을 번호를 최대 6개까지 선택하세요. 현재 0개 선택했습니다.

2

추천 결과

A

회차별 당첨번호

당첨 데이터를 불러오는 중입니다.

최근 당첨번호

B

과거 당첨번호 통계

과거 자료를 정리한 참고 통계이며 미래 결과를 예측하지 않습니다.

번호별 출현 횟수

최근 미출현 기간

홀짝 비율

번호 구간별 분포

연속 번호 출현

자주 함께 나온 번호

C

저장한 번호와 당첨 확인

대상 회차의 공식 데이터가 있으면 자동 비교합니다.

직접 번호 확인

D

GitHub 관리자 화면

비공개 저장소 권한이 관리자 인증을 대신합니다.

운영 방법

  1. GitHub Actions가 매주 공식 당첨번호를 확인합니다.
  2. 저장소 권한이 있는 관리자는 실행 기록과 변경 커밋을 확인합니다.
  3. 가져온 데이터는 구조와 번호 범위를 검증한 뒤 현재 기기에만 적용합니다.

정적 앱 코드에 관리자 비밀번호나 GitHub 토큰을 저장하지 않습니다.

E

설정과 알림

설정은 현재 기기에만 저장됩니다.

알림 방식

알림을 허용하면 앱을 열었을 때 새 당첨 데이터와 저장 번호 결과를 확인해 알려드립니다. 정적 앱은 완전히 닫힌 상태에서 서버 푸시 알림을 보낼 수 없습니다.

꼭 확인해 주세요

추천 번호와 통계는 참고용입니다. 당첨을 예측하거나 보장하지 않으며 모든 번호 조합의 추첨 가능성은 동일합니다.

당첨 여부와 당첨금은 반드시 동행복권 공식 홈페이지 또는 판매점에서 최종 확인하세요.

광고 없는 무료 서비스 · 추천 및 설정 데이터는 현재 기기에 저장됩니다.
