# 로또 번호 도우미

대한민국 로또 6/45 번호를 무작위로 추천하는 접근성 중심 정적 웹앱입니다. 별도 서버, 데이터베이스, 외부 API 또는 광고를 사용하지 않습니다.

## 주요 기능

- 1~100게임 무작위 번호 생성
- 모든 게임에 포함할 번호 최대 6개 선택
- 추천 결과 기기 저장, 복사, 공유 및 PNG 저장
- 추천 번호 한국어 음성 읽기
- 키보드·스크린 리더·200% 확대·고대비 지원
- 모바일과 PC 반응형 화면

## 실행 방법

`index.html`을 브라우저에서 열거나 GitHub Pages 주소로 접속합니다.

## 데이터와 개인정보

추천 번호와 보기 설정은 현재 브라우저의 `localStorage`에만 저장됩니다. 브라우저 데이터를 삭제하면 저장 내용도 사라질 수 있습니다.

## 안내

이 앱의 번호는 무작위로 생성한 참고용 번호입니다. 당첨을 예측하거나 보장하지 않으며, 모든 번호 조합의 추첨 가능성은 동일합니다.
