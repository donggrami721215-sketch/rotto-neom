# 로또 번호 도우미

대한민국 로또 6/45 번호 추천, 공식 당첨번호 검색, 통계와 저장 번호 당첨 확인을 제공하는 접근성 중심 PWA입니다. 별도 서버, 데이터베이스 또는 광고를 사용하지 않습니다.

## 주요 기능

- 1~100게임 무작위 번호 생성
- 모든 게임에 포함할 번호 최대 6개 선택
- 추천 결과 기기 저장, 복사, 공유 및 PNG 저장
- 공식 회차별 당첨번호 검색과 최근 목록
- 출현 횟수, 미출현, 홀짝, 구간, 연속 번호, 공동 출현 통계
- 저장 번호 및 직접 입력 번호의 당첨 결과 확인
- 앱 실행 시 새 회차 브라우저 알림
- 데이터·저장번호 가져오기와 내보내기 관리 화면
- GitHub Actions를 이용한 주간 당첨 데이터 자동 갱신
- 오프라인 캐시와 PWA 설치
- 추천 번호 한국어 음성 읽기
- 키보드·스크린 리더·200% 확대·고대비 지원
- 모바일과 PC 반응형 화면

## 실행 방법

정적 웹 서버에서 실행하거나 GitHub Pages 주소로 접속합니다. 서비스 워커와 설치 기능은 HTTPS 또는 localhost에서 작동합니다.

## 관리자 운영

관리자 인증은 비공개 GitHub 저장소 접근 권한으로 처리합니다. 저장소의 `Update Lotto Data` Actions 작업은 매주 토요일 21시 30분(한국시간)에 공식 동행복권 데이터를 확인하고 변경분을 커밋합니다. 앱 코드에 비밀번호나 GitHub 토큰을 저장하지 않습니다.

## 데이터와 개인정보

추천 번호와 보기 설정은 현재 브라우저의 `localStorage`에만 저장됩니다. 브라우저 데이터를 삭제하면 저장 내용도 사라질 수 있습니다.

## 안내

이 앱의 번호는 무작위로 생성한 참고용 번호입니다. 당첨을 예측하거나 보장하지 않으며, 모든 번호 조합의 추첨 가능성은 동일합니다.
